여행 상황판 (Travel Manager) v2.2.0
====================================

이번에 바뀐 것
--------------

0) 화면 자동 업데이트  ★ 새로 들어갔습니다

  화면을 고칠 때마다 쓰는 사람들이 붙여넣어야 했던 걸 없앴습니다.
  깃허브에 올려둔 화면을 앱이 알아서 받아옵니다.

  못 받아오면 시트에 붙여넣어 둔 화면으로 그립니다. 앱이 멈추지 않습니다.
  켜는 법은 자동업데이트-켜는법.txt 에 한 장으로 적어뒀습니다. (10분이면 됩니다)

  ※ 서버 로직(Code.gs)은 일부러 자동화하지 않았습니다.
    남의 시트를 직접 읽고 쓰는 코드라, 원격 실행은 위험합니다.
    그쪽은 EXE 가 버전을 비교해 안내합니다.

1) 설치 방식이 바뀌었습니다 (배포를 염두에 둔 변경)

  예전 : 내 구글시트를 '사본 만들기' 로 복사
       -> 받는 사람에게 내 친구들 이름·계좌·지출·사진이 그대로 딸려갑니다
  지금 : 받는 사람이 자기 계정에 '빈 시트' 를 만들고 코드를 붙여넣습니다

  EXE 마법사가 Code.gs 와 Index.html 을 버튼 한 번으로 복사해 줍니다.
  붙여넣기만 하면 됩니다.

2) 업데이트 안내

  앱에 들어 있는 코드 버전과 시트에 올라간 버전이 다르면
  위쪽에 띠가 뜨고, 붙여넣는 순서를 화면으로 알려줍니다.
  (배포 관리 -> 연필 -> 새 버전 까지 안내합니다)

3) 부분 참여 정산

  지출을 넣을 때 '이 지출을 나눌 사람' 을 고를 수 있습니다.
  아무도 안 고르면 참석자 전원이 나눕니다.
  야식을 세 명만 먹었으면 그 세 명만 고르면 됩니다.

4) 백업 되돌리기 / 다음 여행 준비  (설정 탭 > 관리자)

  · 백업 내려받기 — 전체 자료를 파일 하나로
  · 백업에서 되돌리기 — 사고가 나면 그 파일로 복구
  · 다음 여행 준비 — 명단·계좌는 남기고 지출·일정·숙소만 비우기

5) 시트 메뉴에 [내 자료 전부 비우기 (배포용)]

  시트를 남에게 넘기기 전에 한 번 누르면 깨끗해집니다.


1) 웹앱 업데이트
----------------

구글시트 > 확장 프로그램 > Apps Script 에서
google-apps-script 폴더의 Code.gs 와 Index.html 을 붙여넣고 저장,
배포 > 배포 관리 > 연필 > 버전 [새 버전] > 배포

  ※ '새 배포' 를 누르면 주소가 바뀌어 친구들 링크가 끊깁니다.
    반드시 '배포 관리' 의 연필을 쓰세요.

지출대장에 '참여자' 열이 자동으로 추가됩니다. 기존 지출은 그대로 있습니다.

설정 탭 맨 아래가 [화면 2.2.0 · 서버 2.2.0] 이면 반영된 것입니다.
괄호로 출처도 같이 나옵니다.  최신 / 최신(보관중) / 시트


2) EXE 만들기
-------------

빌드 전에 최신 코드를 앱 안에 넣어야 합니다.

    cd C:\Users\user\Travel-Manager\desktop-app
    copy ..\google-apps-script\Code.gs     code\Code.gs
    copy ..\google-apps-script\Index.html  code\Index.html
    npm install
    npm run dist

  -> dist 폴더에 TripBoard-Setup-2.2.0.exe / TripBoard-Portable-2.2.0.exe

이 code 폴더가 앱이 복사해 주는 코드이고, 업데이트 알림의 기준도 이 파일입니다.


3) 깃허브에 올리기
------------------

GITHUB-올리는법.txt 를 그대로 따라가면 됩니다.

  ※ ui\config.js 는 이제 쓰지 않습니다. 시트 주소를 앱에 넣어둘 필요가 없어졌습니다.
