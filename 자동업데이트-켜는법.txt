화면 자동 업데이트 켜는 법 (한 번만 하면 됩니다)
==================================================

이걸 켜두면, 앞으로 화면을 고칠 때 쓰는 사람들이
Apps Script 에 붙여넣지 않아도 자동으로 최신 화면을 받아 씁니다.

원리는 간단합니다.
  시트 안의 화면을 쓰는 대신, 깃허브에 올려둔 화면을 받아와 그립니다.
  받아오지 못하면(인터넷 차단·주소 오류) 시트 화면으로 그립니다. 그래서 앱이 멈추지 않습니다.


1단계. 깃허브 저장소를 공개로 만들기
-------------------------------------

GITHUB-올리는법.txt 대로 웹에서 올립니다. 공개(Public) 저장소로 만듭니다.

  ※ 이미 비공개로 만들어 두셨다면
    github.com 저장소 > Settings > 맨 아래 Danger Zone
    > Change repository visibility > Public

  올리기 전에 백업 JSON 파일이 섞여 있지 않은지 꼭 확인하세요.
  (참가자 이름·계좌가 들어 있습니다)


2단계. Pages 켜기
------------------

github.com 의 내 저장소로 갑니다.

  Settings > 왼쪽 메뉴 Pages

  Source  : Deploy from a branch
  Branch  : main   /  폴더는  /docs   를 고릅니다
  [Save]

1~2분 뒤 새로고침하면 위에 주소가 나옵니다.

  https://<내아이디>.github.io/travel-manager/

이게 기본 주소입니다. 화면 파일은 그 뒤에 Index.html 이 붙습니다.

  https://<내아이디>.github.io/travel-manager/Index.html

브라우저에서 이 주소를 열어 하얀 로그인 화면이 보이면 성공입니다.
(여기서는 로그인이 안 됩니다. 시트와 연결되지 않은 껍데기라 정상입니다.)


3단계. Code.gs 에 주소 적기
----------------------------

Code.gs 맨 위쪽 23번째 줄 근처입니다.

    var UPDATE_URL = '';

여기에 1단계에서 나온 기본 주소를 넣습니다. 끝에 / 를 꼭 붙입니다.

    var UPDATE_URL = 'https://<내아이디>.github.io/travel-manager/';

고친 Code.gs 를 Apps Script 에 붙여넣고 저장한 뒤
배포 > 배포 관리 > 연필 > 버전 [새 버전] > 배포.

  ※ 이 한 줄이 들어간 Code.gs 를 앞으로 배포용으로 쓰시면 됩니다.
    받는 분들은 아무것도 설정할 필요가 없습니다.


4단계. 확인
-----------

앱에 들어가 설정 탭 맨 아래를 봅니다.

    화면 2.1.0 (최신) · 서버 2.1.0

괄호 안이 이렇게 나오면 성공입니다.

    최신          방금 깃허브에서 받아왔습니다
    최신(보관중)   받아둔 것을 쓰고 있습니다 (6시간마다 다시 받아옵니다)
    시트          자동 업데이트가 꺼져 있거나 주소가 비어 있습니다
    시트(가져오기 실패)   주소는 있는데 못 받아왔습니다 → 주소를 확인하세요


앞으로 화면을 고칠 때
----------------------

1. Index.html 을 고칩니다
2. 깃허브 저장소 > docs 폴더 > [Add file] > [Upload files]
3. 고친 Index.html 을 끌어다 놓고 [Commit changes]

끝입니다. 쓰는 사람들은 최대 6시간 안에 자동으로 새 화면을 받습니다.
바로 보고 싶으면 설정 탭 > [지금 확인] 을 누르면 됩니다.

  ※ 화면만 고쳤다면 Index.html 의 화면 버전(uiVer)만 올리고
    Code.gs 의 APP_VERSION 은 그대로 두세요.
    그래야 EXE 가 "붙여넣으세요" 안내를 띄우지 않습니다.


서버 로직(Code.gs)을 고쳤을 때는
---------------------------------

이건 여전히 붙여넣어야 합니다. 시트를 직접 읽고 쓰는 코드라
원격 실행은 위험해서 일부러 자동화하지 않았습니다.

대신 EXE 가 알아서 알려줍니다.
APP_VERSION 을 올리고 desktop-app\code\Code.gs 에 복사해 두면,
쓰는 사람 화면 위에 "새 버전이 있습니다" 띠가 뜨고
붙여넣는 순서까지 안내합니다.


끄고 싶으면
-----------

쓰는 사람: 앱 설정 탭 > 화면 자동 업데이트 > 끔
나 자신  : Code.gs 의 UPDATE_URL 을 빈 문자열로

끄면 시트에 붙여넣어 둔 화면을 그대로 씁니다.
