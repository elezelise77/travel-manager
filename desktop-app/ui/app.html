여행방 만들기

아래 순서대로 한 번만 하면 됩니다. 만들어진 주소를 친구들에게 보내면, 친구들은 아무것도 설치하지 않고 링크만 눌러 씁니다. 모든 자료는 내 구글 계정에 새로 만든 시트에 저장됩니다. 남의 시트를 복사하는 게 아니라, 빈 시트에서 시작합니다.

1
빈 구글시트 만들기

아래 버튼을 누르면 브라우저에 새 스프레드시트가 하나 만들어집니다. 왼쪽 위 제목을 우리 여행 처럼 알아보기 쉽게 바꿔두세요.

이미 만들어 둔 시트를 쓰셔도 됩니다.
2
코드 두 개 붙여넣기

시트 위쪽 메뉴 확장 프로그램 → Apps Script 를 누릅니다. 아래 버튼으로 코드를 복사해서 차례대로 붙여넣으세요.

① Code.gs 편집창을 클릭하고 Ctrl+A → 붙여넣기 → Ctrl+S
② Index.html 왼쪽 파일 옆 ＋ → HTML → 이름을 Index 로 (뒤에 .html 은 붙이지 않습니다) → 붙여넣기 → Ctrl+S
파일 이름은 반드시 Index 여야 합니다. 대소문자도 그대로입니다.
3
인터넷 주소 만들기 (배포)

같은 Apps Script 화면 오른쪽 위 배포 → 새 배포 → 톱니바퀴에서 웹 앱 선택 → 실행 계정 나, 액세스 권한 모든 사용자 → 배포.

처음 배포하면 권한을 묻는 창이 뜹니다. 액세스 승인 → 내 계정 → 고급 → (프로젝트 이름)(으)로 이동 → 허용 순서로 눌러주세요. 내 시트와 내 드라이브(사진 저장)에만 접근하는 권한입니다.

액세스 권한을 모든 사용자로 해야 친구들이 구글 로그인 없이 들어올 수 있습니다. 그래도 아무나 못 봅니다 — 앱 안에서 이름과 비밀번호로 다시 확인합니다.
4
나온 주소를 여기에 붙여넣기
